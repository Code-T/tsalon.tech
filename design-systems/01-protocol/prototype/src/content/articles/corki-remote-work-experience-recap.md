> Corki 这场分享的录播发布于 2023 年 3 月 8 日，活动举办日期未确认。公司制度、职位机会、薪酬及个人经历均为当时交流内容。

在上海工作多年后，Corki 因结婚和陪伴家人的考虑回到家乡，也再次选择了远程工作。他把这次分享定位为普通开发者的经验交流，重点是远程怎样进入自己的生活，以及真正开始后每天怎样工作。

## 两次远程经历，对应不同生活阶段

第一次机会出现在 2018 年前后。Corki 与朋友合作接项目，之后进入对方公司，开始远程工作，也曾边工作边旅行。2020 年左右，他因疫情及其他原因重新坐班；后来希望留在家人身边，又经朋友所在社群的介绍找到远程岗位。

主持人先提到他在上海工作七年、其中有过两年在国内远程的经历。Corki 说，这一次离开上海与结婚有关，想回老家陪伴家人，因此重新寻找能在当地继续做前端开发的岗位。两次选择远程的起点并不一样：第一次更像工作方式的探索，第二次要解决的是生活地点与工作机会之间的冲突。他最终得到的岗位来自社群里朋友的介绍，而非仅靠公开投递。

前一次远程始于与朋友合作项目，随后进入对方公司。他也尝试过一边旅行一边工作；后来回到办公室，再次想离开一线城市时，最难放弃的是当地更集中的开发机会。社群里的朋友推荐给他新岗位，才让“回家生活”和“继续做前端”能够同时成立。这是他自己两次转向远程的实际路径，并不是离开上海后自然就有同等职位可选。

他的感受是，重新安排地点后，工作之外更容易留出陪伴、锻炼和学习的时间，生活压力和消费期待也发生了变化。这是自己的工作和生活组合带来的体验，并不能说明所有远程岗位都没有加班或都会改善身体状态。

## 自由安排的背后，是明确的开发流程

当时他的常规工作时间大致与北京时间白天一致。每天先查看 GitHub 上的任务，大需求拆成可分配的小项，每项工作由明确的成员负责。开发前还要估算编码、自测和 review 时间，而不是只报一个写完代码的时间。

这套流程给“远程能否看见进度”一个具体答案。每天打开任务列表，先确认自己负责的需求；大任务拆成几个人能分别完成的小项，再估计写代码、自己验证和请同事评审各要多久。提交工作以后仍需留出 review 与返工时间，不能把第一次写完当成交付结束。这样即使成员不在同一间办公室，其他人也能从任务与讨论记录里知道谁正在处理哪一部分。

团队每天有一次约二十分钟的视频沟通，同步已完成事项、当天计划和遇到的问题，其余时间更多通过 Slack 交流。涉及海外同事时，消息未必能立即得到回应，因此文字要尽量准确地交代问题和必要背景，减少跨时区反复询问。

Corki 介绍，会议把前一天完成的工作、当天安排和阻碍集中说清楚，给全员一个固定的碰面窗口。其余时间如果碰到美国同事已下班，就先把问题留在协作工具里，等对方上线回复。现场主持人追问跨时区怎样约定会议，他补充说，美国成员所在时段接近下班，中国成员在早晨参加，然后双方在非重叠时段用留言衔接。这个安排并没有消除等待，而是让同步时间和异步工作各有用途。

他介绍了 React、TypeScript、设计稿协作工具等工作背景。远程建立在信任上，也要求个人自我约束、主动反馈，并按约定完成工作。

具体工具也服务于不同环节：当时前端主要使用 React、TypeScript 和 Next.js，设计协作使用 Figma，事项会在文档与任务工具中留下记录。Corki 把这种工作方式的前提说成信任，但信任要靠可见的任务进展、能及时求助以及如期交付维持。待在家里并不意味着可以整天躺着等人催促；没有人站在旁边监督时，自我管理更直接影响其他人的排期。

## 什么阶段适合尝试

Corki 倾向于有一定技术和职场经验后再考虑远程，原因是需要独立理解任务、处理问题和沟通。他在原片中给出过工作年限与职级的参考，但这是个人建议，不是所有远程岗位的统一门槛。

他给过“工作三年左右再考虑”的个人参考，理由是刚入行时往往还需要面对面地观察团队怎么拆需求、处理冲突、向同事求助。远程岗位未必会每天有人坐在旁边带着完成任务，独立推进和主动说明困难很重要。不过这不是说新人无法远程，而是提醒求职者先判断岗位是否提供足够的指导，以及自己遇到阻碍时能否及时把问题说清。

他还转述过照顾家人、回乡后缺少合适岗位、偏好自主安排等动机。这些只是帮助理解需求的例子：同样叫远程，有人更需要地点自由，有人更在意家庭安排，也有人在寻找新的职业路径。

他借用其他远程工作者归纳的几类情况，让听众判断自己为什么想远程：需要照顾孩子或老人、想回乡而本地缺少合适岗位、不喜欢高度依赖当面社交、希望调整职业处境，或单纯偏爱更自由的安排。这些动机之间并不相同。若主要问题是现有团队缺少成长机会，换了办公地点未必能解决；若主要问题是必须留在家乡，招聘范围则可能因为远程而扩大。

## 求职准备：简历、项目与沟通能力

他建议按目标公司准备中文或英文简历，突出自己的技术能力和项目中的具体工作。自己接触过的面试常有多轮，可能讨论框架、项目代码、GitHub 记录，也可能给一个模块让候选人限时完成；较复杂岗位还会关注算法和系统设计。

他描述的准备顺序是先看公司与岗位，再决定用哪份简历，而不是只有一份英文简历就能投遍所有团队。面试官若问项目架构，候选人需要说清自己负责的部分、为什么这样组织代码；若看公开仓库，也会从提交与实现里了解实际能力。没有公开仓库时，可准备能展示的过往代码片段，但仍要说明保密边界。限时模块练习则同时考察拆任务、实现、自测和呈现结果。

主持人问英文简历要突出什么，Corki 的回答是简洁地说明技术能力和项目架构经验，而不是把用过的工具一股脑列上去。面试方可能直接看 GitHub 或过往项目代码；没有公开仓库，也要准备能解释自己实际做过什么。有的公司会在面试前给出一个模块，让候选人在几天内完成。这样的作业不仅考察写法，也让对方看到候选人如何组织、验证和交付一个相对完整的功能。

英语是另一项准备。Corki 当时所在团队较重视读文档和通过文字沟通，口语要求相对不同；他的面试包含英文自我介绍，并没有完整的统一语言考试流程。但他仍认为听说能力更强能够扩展机会，不能把自己一次面试的要求当作海外公司的共同标准。

在渠道上，他提到远程工作社区、LinkedIn、Upwork 及朋友介绍，也曾看到其他招聘平台上的远程职位。他自己的这份工作来自社群内推。现场关于公司是否招人的回答属于当时信息，不能据此视为仍有效的招聘公告。

## 英语、算法、学历与年龄的具体追问

对于英语学习，他介绍自己报了线上课程，在周末和下班后继续学习。算法准备则建议参照目标公司的考察要求；原片提到的刷题数量只是经验表达，不能把做完一个题单当成能力或录用保证。

主持人把算法问题问得很具体：如果一个人能完成某张题单的大部分，是否就算准备够了？Corki 没有给出通用及格线，而是建议参考目标公司与国内较大技术团队的考察强度，持续做题并讲清思路。同样，英语也不能只在投递前突击：他当时报了周末课程，下班后仍上网课，因为日常读写、会议听说和面试表达是不同的使用场景。

这一段问答呈现出英语要求的层次差别。他本人面试时只做过一段英文自我介绍，日常与海外成员主要用英文读文档和发文字消息；他所在团队有华人管理者，因此口语门槛没有他想象得那么高。主持人追问是否需要现场翻译文档，他说自己没有经历统一的语言测试。Corki 同时强调，若能听懂会议、口头解释问题，能看的岗位会更多。英语不是“够不够远程”的单一开关，而要看团队真实用它完成哪些协作。

学历问题在问答中出现了两次。Corki 介绍，自己接触的一些全职岗位会写学历要求，部分项目或兼职机会则更看重经验和代码；他本人没有遇到主持人所问的学历公证步骤。对于自考、专升本等具体情况，他没有给出能覆盖各公司的认证结论。

对于超过四十岁是否还有机会，他回答自己知道更年长的人也在做远程。这说明个别路径存在，并不消除不同岗位的差异，也不意味着远程能够保证避开所有职业风险。

主持人先问三十五岁左右是否会因年龄失去机会，后来又把问题推到四十岁以上。Corki 的回答来自身边见闻：海外远程团队仍有年长开发者，他不把某个年龄看作绝对停止线；但他在主讲中也说，裁员风险不会因为在家办公就消失。年龄问题最终还是回到能否承担岗位所需工作，以及是否持续学习，而不是把远程当成规避职业变化的保险。

## 前端、全栈和架构岗位有什么不同

按当时接触的职位，Corki 觉得前端远程机会相对常见，React 与全栈能力也经常出现在要求里。他提到 Node.js、Go 等服务端方向，以及前端 lead、架构类岗位的存在；对更高责任岗位，讨论又回到代码、项目架构和解决复杂问题的能力。

主持人把问题一步步缩小：先问开发岗位里前端是否常见，再问纯前端和全栈有什么差别，接着问全栈通常要补哪门后端技术。Corki 按个人见闻说，海外团队里 React 较常见，若能承担 Node.js 等服务端工作，职位选择可能更宽，也见过 Go 的要求。但“全栈”并不是只多会一种语言；遇到前端 lead 或架构职位，面试还会看项目怎样分层、代码怎样维护、复杂问题如何处理。

原片还举过月度两三万、初级一两万、年度六十万等报价样本，但没有完整交代币种、地区、税前税后和样本范围。因此这些数字只能作为那次交流中的个人见闻，不能组成可比较的薪酬表，更不能当成目前的市场报价。

## 报酬、保障与职位真实性要分别看

在主讲中，Corki 介绍过自己当时通过支付平台收到报酬、另行安排当地社会保障的情况，也提到假期与国内公共假期大体衔接。这些只是一个人的合同和公司安排，不能直接套用到其他国家、公司或雇佣形式。

他提醒不要只看高报价或远程标签，还要了解对方实际做什么、报酬如何确定。现场对 Web3 岗位比例的说法来自个人印象，没有给出调查口径；对某些岗位真实性及代币报酬的担忧，需要结合具体合同、业务与当地要求核实。

主持人顺着当时大量 Web3 职位追问：应聘时要注意什么？Corki 把“区块链”标签与实际业务分开，担心有人借标签招聘开发赌博等违法业务，也提醒注意以自家代币支付报酬的安排。能否接受一个职位，不能只由标题和报价决定，还得问清产品、合同主体、支付条件和自己实际要写的功能。他没有给出一份经过统计的 Web3 岗位比例。

## 团队分布与回乡后的生活

关于组织结构，他介绍当时管理层及部分技术成员在美国，其他成员分布在中国，公司采用远程方式。日常会议提供固定碰面机会，其余协作依靠文字与任务安排。问答中的人数和岗位描述属于那个阶段，不代表公司今天的规模。

主持人还想知道中国的同事是集中坐班还是分散远程。Corki 回答当时公司整体采用远程，管理层和部分后端成员在美国，开发人员多在中国不同城市。早晨的会议让两边处于工作时段交界的人碰面；会后若美国同事已经下班，就把问题、上下文和需要对方决定的事留在消息里。这解释了为什么他一方面强调每天见面，另一方面又强调文字表达的准确性。

回到家乡后，他更常把闲暇时间留给伴侣、锻炼和英语学习。最后关于合同的追问，他确认签过合同，也表达了跨境争议中维权时间与成本的担忧。合同约定与争议解决仍要结合具体安排判断。

主持人问回乡后生活是否真的更平衡，Corki 没有把改变全归功于工作制度，而是说自己可以陪伴伴侣、运动，并将剩下的时间用于英语。他提到体重和身体状态较从前改善，这是个人经历；更可迁移的是他为家庭、健康和学习重新安排了时间。关于合同，他提醒跨境争议可能带来较高的时间与沟通成本，签约前应了解实际合同主体与约定。

他对远程的定位是多一种选择。是否尝试、何时尝试，需要结合自己希望的生活、已有能力和具体机会，而不是为了远程这个形式本身作决定。
