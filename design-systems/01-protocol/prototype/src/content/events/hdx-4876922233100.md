## 活动介绍

白天逛 S 创，晚上把 Agent 打开：AI 下班小聚，看作品、玩挑战、喝一杯。

不管你是在做 side project、开发实际落地的 Agent 产品，还是在探索 AI 的前沿玩法，开发者、产品人、创业者和 AI 爱好者都欢迎来玩。

除了 Agent 分享和现场开搓，现场还准备了鸡尾酒、软饮畅饮，以及瓶装啤酒和分享小食。想动手，带上电脑；想围观，带着好奇心来。一个人来也欢迎，现场认识新朋友。

## 环节亮点

### Agent 闪电演讲

精选 3 至 5 个真实作品闪电演示。看效果，聊做法，也聊踩过的坑。感兴趣，就找作者当面聊聊技术细节与实现路径。

### Agent Battle 与现场开搓

现场开搓 Agent，限时挑战。无论是单人作战还是临时组队，带上你的 IDE 和灵感现场一较高下。

### Trash Demo 现场评选

最有用、最没用、最离谱，全部由现场观众投票选出。不参加挑战，也能当评委。

### 自由交流与 Vibe

音乐、饮品、自由交流。聊聊 AI，也聊最近在折腾什么。想小酌就喝一杯，不喝酒也一样欢迎。

## 参与方式

本场为线下活动，通过[活动行](https://2142604620453.huodongxing.com/event/4876922233100)预约报名。活动地点位于上海市徐汇区云绣路29号103室（模速第三空间）。
